Dashboard Layout Gallery

Every distinct XMS BI dashboard layout, drawn to scale on the 12-column grid. Companion to dashboard-design-handoff.md.

Widths shown are the md breakpoint (desktop). Queried live from UAT report DB on 2026-07-31 — 82 live grids, collapsing to the 16 patterns below.

Reading this: each block is one card; its width is its md span out of 12. Hatched blocks are dead columns — a row that doesn't sum to 12. The number at the right of each row is its column total.

Layout source: DashboardGridItem in the report database. Card content, titles and colours come from core.core.VisualisationQueries on the Managed Instance and are not configurable here — see the handoff doc §3.
